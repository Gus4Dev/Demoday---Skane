# Demoday---Skane
Projeto realizado durante o curso PROA Profissão, como desenvolvimento de aprendizado durante o curso desenvolvemos um dispositivo e um aplicativo para ajudar a usuários de carro, para saber sobre as informações do seu carro de maneira fácil, rápida e a qualquer hora. 

A Skane é um dispositivo que é usado na entrada OBD-II do carro, conectado ao aparelho celular via bluetooth, trazendo diretamente todas as informações no aplicativo. Trazendo soluções e orientações sobre o seu veículo, nele você também pode medir e acompanhar os litros de combustível que tem no seu tanque de gasolina. Fazendo com que na hora de abastecer ele mede e calcula os litros antes e depois do abastecimento, dizendo se está correto o que foi pedido com o que realmente chegou para você. 

Contamos com uma comunidade, interativa para saber a confiança dos postos de gasolina do bairro. mitigando gastos excessivos com a manutenção do veículo.
